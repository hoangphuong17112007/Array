# Xác định yêu cầu của bài toán
- Đề bài yêu cầu nhập hai mảng X và Y theo thứ tự đã được sắp xếp sẵn từ bé đến lớn 
- Sắp xếp lại thứ tự các mảng
# Giải thuật bài toán
- Vì các mảng đã được sắp xếp sẵn nên ta chỉ cần so sánh cuối mảng X với đầu mảng Y 
- Nếu đẽ kết thúc vòng lặp while sẽ chuyển sang sắp xếp trong chính các mảng X và Y
